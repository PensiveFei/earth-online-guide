# 📝 文章模板

所有技能篇按此结构撰写。复制以下骨架，逐节填写。

## 必填元信息

- 标题：动词开头，一句话说清（例：把米饭蒸得粒粒分明）
- 难度：⭐（1–5）
- 耗时：约 X 分钟
- 费用：约 X 元

## 结构骨架

```markdown
# 标题

> 一句话说明这篇解决什么

- 难度：⭐☆☆☆☆
- 耗时：约 X 分钟
- 费用：约 X 元

## 准备

- 要买 / 要带的东西（含大约价格）

## 步骤

1. 每一步只做一件事
2. 关键操作写清楚「做到什么程度」（例：水开后转小火，而不是「煮一会儿」）

## 避坑

- 常见翻车点（真实经历优先）

## 安全提示

⚠️ 涉及燃气 / 用电 / 刀具 / 医疗时必填，写清风险与应急做法

## 常见问题

- Q：……？A：……

## 进阶

- 相关链接（如 HowToCook）
```

## 三条写作约定

1. **第一次视角**：默认读者从没做过，不写「众所周知」「很简单」
2. **步骤可验证**：每一步读者都能判断「做到位了没有」
3. **事实优先**：拿不准的细节宁可删掉，不猜

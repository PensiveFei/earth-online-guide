# 挂号全流程

## 就诊前准备

准备身份证、社保卡/医保码、手机。确认症状。不确定挂什么科可在医院导诊台咨询或线上问客服。选择医院：常见病可去社区卫生服务中心或二级医院，复杂病去三级医院。

## 线上挂号

通过医院官方公众号、App、支付宝/微信城市服务、114预约挂号平台等。首次使用需实名注册，添加就诊人。选择科室、医生、日期和时间段。支付挂号费后预约成功。保留预约信息。

## 就诊当天

按预约时间提前15-30分钟到达医院。首次就诊需到窗口或自助机建档、取号或签到。部分医院可直接到科室分诊台扫码签到。等待叫号，不要远离。叫号后进诊室。

## 就诊与检查

向医生说明症状、持续时间、既往病史、用药情况、过敏史。医生开具检查单或处方。到缴费窗口或自助机缴费，然后到对应科室检查、取药。需要发票可在自助机打印。

## 必要物品与费用

身份证、社保卡或医保码、手机、既往检查资料。普通门诊挂号费约10-50元，专家号约50-200元，具体按医院等级。检查费和药费另计，可医保结算。

## 容易踩错的点

- 挂错科室
- 没带有效证件
- 迟到爽约被系统拉黑
- 没签到直接等叫号
- 不记得用药过敏史
- 没带既往检查报告导致重复检查
- 没走医保支付直接全额自费

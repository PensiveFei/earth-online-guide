# 常见小病怎么处理

## 家庭常备物品

体温计、碘伏、棉签、创可贴、纱布、医用胶带。家庭常备药可按需准备：退烧止痛药如对乙酰氨基酚、布洛芬；腹泻时用的口服补液盐、蒙脱石散；过敏时用的氯雷他定等抗组胺药。用药前看说明书，儿童、孕妇、老年人及有基础病者先咨询医生或药师。

## 常见轻症处理

发热可先物理降温、多饮水，体温较高或明显不适时用退烧药。腹泻重点防脱水，喝口服补液盐，清淡饮食。轻微擦伤用清水冲洗、碘伏消毒、创可贴或纱布覆盖。普通感冒以休息、饮水、对症处理为主。症状不缓解或加重时就医。

## 必须就医的情况

持续高热不退；呼吸困难、胸痛；意识不清、抽搐；严重腹痛、呕吐；腹泻伴血便或明显脱水；外伤出血不止、伤口深或污染重；过敏出现面部肿胀、呼吸困难。儿童、老人、孕妇出现异常症状应尽早就医。

## 容易踩错的点

- 自行滥用抗生素
- 多种感冒药同时吃导致成分过量
- 腹泻不补液只吃止泻药
- 小伤口不消毒
- 症状加重还硬扛
- 轻信偏方
## 官方渠道

- [国家药品监督管理局](https://www.nmpa.gov.cn)：药品批准文号与说明书查询
- 症状加重或持续不缓解请及时就医，本文不构成诊疗建议

# 看房清单

## 看房流程

尽量白天和晚上各看一次。白天看采光、通风、墙面、漏水、小区环境。晚上看隔音、周边噪音、照明、治安。

进入房间后按顺序检查：门窗能否正常关闭反锁；墙面天花板是否有水渍、霉斑；地面是否渗水；卫生间水压、马桶冲水、地漏是否堵塞；厨房燃气灶、抽油烟机、水槽能否正常使用；空调、热水器、洗衣机、冰箱是否运行正常；插座数量和位置；家具是否损坏；网络信号和手机信号；小区进出管理和快递外卖情况。

## 需要当场确认的问题

水、电、燃气、网费、物业费由谁承担；房租是否含税；押金数额；租期；能否养宠物；能否转租；维修由谁负责；冬天供暖方式；有无车位。所有约定最好写入合同或微信文字确认。

## 必要物品与费用

身份证、手机、充电器、测量工具、纸笔。看房免费。成交后可能产生中介费、押金、首期租金。

## 容易踩错的点

- 只看一次就签
- 不试热水器和空调
- 不检查下水道
- 不问物业费
- 不问能否转租
- 不问维修责任
- 不看夜间噪音
- 不检查门窗锁

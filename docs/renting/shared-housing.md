# 合租注意事项

## 合租前确认

确定合租对象是朋友、熟人还是陌生人。了解室友作息、职业、是否养宠物、是否经常带人留宿。确认房屋是整租后分租，还是与二房东同住。优先与房东直签合同，或确认二房东有转租权限。

## 费用分摊

房租按房间大小、朝向协商分摊。水、电、燃气、网费、物业费按人头或房间分摊，并写入书面约定。公共区域维修费用由谁承担要提前说清。公共消耗品如纸巾、洗洁精、垃圾袋是否轮流购买或各自购买。

## 公共区域规则

明确卫生值日、厨房使用、冰箱空间、洗衣机时间、公区物品摆放、访客留宿、噪音时段、是否养宠物。规则尽量具体，避免只说“互相理解”。

## 安全与隐私

个人房门锁好，贵重物品和证件不要随意放。核实室友身份信息。异性合租注意边界，避免单独处理纠纷。发现室友有违法行为及时报警。合租期间保存房租转账记录。

## 必要物品与费用

个人生活用品、房门锁、贵重物品收纳箱。合租押金和租金按约定分摊。公共费用需要留存缴费凭证。

## 容易踩错的点

- 费用分摊不清
- 室友经常带人留宿
- 公共区域脏乱
- 有人提前退租导致费用空缺
- 二房东跑路
- 只做口头约定
- 与陌生人合租不核实身份
- 个人物品随意放在公共区域

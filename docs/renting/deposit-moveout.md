# 押金与退租

## 入住时留证

交押金前，对房屋整体状况拍照、录像，重点拍墙面、地板、家具、家电、卫生间、厨房。记录水、电、燃气表底数。损坏或瑕疵提前告知房东并写进合同，避免退租时算到自己头上。

## 退租流程

按合同提前通知房东或中介，一般提前30天。退租前清理房间，恢复入住时状态，正常使用磨损除外。结清水、电、燃气、网费。与房东或中介现场交接，核对家具家电和底数。验收无异议后，签退租确认书或微信确认。押金退还时间一般当场或几个工作日内，按合同执行。

## 押金被扣怎么办

正常磨损如墙面轻微发黄、地板正常划痕，不应扣除押金。房东要求扣款的，要求提供损坏证据、维修票据和扣款明细。协商不成，可向12315、住建部门投诉，或通过人民法院小额诉讼解决。不要直接换锁或损坏房屋。

## 必要物品与费用

入住照片、视频、合同、水电气底数记录。退租可能产生清洁费、维修费，费用是否由押金扣除需双方确认。押金一般为一个月租金。

## 容易踩错的点

- 不提前通知导致违约
- 入住时没拍照留证
- 水电气未结清
- 交房时没签退租确认书
- 押金退还时间不写入合同
- 正常磨损被算成损坏
- 被扣款不索要票据
## 官方渠道

- [中国法律服务网 12348](https://www.12348.gov.cn)：押金纠纷免费法律咨询
- 「人民法院在线服务」小程序：押金诉讼可网上立案

# 找房渠道

## 常用渠道

线上平台：贝壳、链家、自如、我爱我家、58同城、安居客等。豆瓣租房小组、闲鱼、小红书有房东直租或转租信息，但需要自己核实。线下渠道：目标小区公告栏、物业、门卫、附近中介门店。

## 找房流程

先确定预算、通勤时间、整租或合租。在平台筛选区域、价格、户型，联系发布者确认房源是否真实、价格是否含物业费、能否看房。看房前不要交任何费用。现场看房后再决定。

房东直租要核对房产证和房东身份证。公寓或中介房源要问清中介费、服务费、付款方式。二房东转租必须看原合同，确认剩余租期和房东是否同意转租。

## 必要物品与费用

手机、身份证、地图App、看房记录表。中介费一般为首月租金的一半或一个月，各城市不同。公寓可能收服务费。看房本身通常免费。

## 容易踩错的点

- 低价精美房源引流后说已租
- 图片与实际不符
- 二房东没有转租权限
- 要求先交定金或押金再看房
- 不在正规平台交易
- 不核验房东身份

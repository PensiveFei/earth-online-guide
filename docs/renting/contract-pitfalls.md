# 合同避坑

## 签合同前核验

出租人是房东的，核对房产证原件、房东身份证原件，确认房屋地址与房产证一致。出租人是二房东的，核对二房东身份证、原租赁合同、房东同意转租的书面文件。出租人是中介或公寓的，确认公司名称和签约主体。

## 合同必备内容

双方姓名、身份证号、联系方式；房屋完整地址；租期起止日期；月租金和押金数额；付款方式和付款日期；水、电、燃气、网费、物业费、卫生费承担；家具家电清单；维修责任划分；违约责任；退租条件；转租约定；续租方式；钥匙数量；交房日期。

## 签订时注意

逐条阅读，空白处划掉或写“无”。费用写清金额和支付周期。租金是否含税、是否含物业费要写明。抄录入住时的水电气底数。家具家电清单签字确认。房屋现状拍照、录像，发给房东或中介留存。口头承诺写入合同或保留微信聊天记录。

## 必要物品与费用

身份证、房产证核验材料、合同文本、笔、手机。费用包括租金、押金、中介费、物业费、网费等。押金常见为一个月租金，付款方式常见押一付一或押一付三。

## 容易踩错的点

- 不核验房产证和身份证
- 签空白合同
- 不看清违约条款
- 维修责任写“租客自理”
- 口头承诺不写入合同
- 不抄水电底数
- 家具家电清单缺失
- 签完后不拍照留证
## 官方渠道

- 当地住建委 / 房管局官网：租房合同示范文本下载、中介机构备案查询
- [中国法律服务网 12348](https://www.12348.gov.cn)：免费法律咨询

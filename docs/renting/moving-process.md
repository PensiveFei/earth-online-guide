# 搬家流程

## 搬家前准备

确定搬家日期，提前3至7天联系搬家公司或预约货运平台。提前打包，按房间分类装箱，箱外标注房间和易碎品。证件、银行卡、贵重物品、充电宝随身携带，不要放入纸箱。提前办理宽带移机或注销，变更快递、银行、手机号等地址。需要物业放行条的提前办理。

## 打包与搬运

准备纸箱、胶带、气泡膜、记号笔。重物装小箱，轻物装大箱。刀具等尖锐物品用硬纸包裹。大件家具提前确认是否需要拆装。搬运当天与师傅确认费用，包括车费、楼层费、大件费、拆装费，避免现场加价。全程跟车或开启行程共享。到新家后按房间标签摆放，先清点箱数，再检查物品是否损坏。

## 搬家后处理

旧房打扫干净，恢复原状，拍视频留证。与旧房东或中介交接，结清费用，拿回押金。新家检查水、电、燃气、门窗、网络是否正常。

## 必要物品与费用

纸箱、胶带、气泡膜、记号笔、随身证件包。小型同城搬家一般几百元，跨城或大件较多费用更高。楼层费、拆装费、大件费需提前问清。平台预约通常比临时叫车便宜。

## 容易踩错的点

- 临时找车被加价
- 不确认费用导致现场加价
- 证件贵重物品混在纸箱里丢失
- 不提前预约
- 不买搬运保险
- 不清理旧房导致押金被扣
- 不检查新家水电就签收

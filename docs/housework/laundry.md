# 洗衣服

## 分类与准备

深浅色分开洗，内衣外衣分开洗。不同材质的水洗要求不同，先看衣物水洗标。拉链拉上、扣子解开，掏空口袋。羊毛、真丝等娇贵材质用手洗或洗衣机专用程序。

## 洗涤操作

洗涤剂按包装说明的用量使用，过量会导致漂洗不净。棉质衣物可用标准程序，深色和易掉色衣物用冷水。羽绒服用羽绒服程序或轻柔程序。沾了油污的可先局部预处理再机洗。

## 晾晒

洗后及时取出晾晒，避免闷在洗衣机里发臭。深色衣物反面晾晒防褪色。羊毛衫平铺晾干，不用衣架挂晒防变形。

## 容易踩错的点

- 深浅混洗染色
- 不看水洗标导致缩水
- 洗涤剂过量
- 拉链不拉划伤其他衣物
- 白色和深色同洗
- 衣物长时间闷在洗衣机里

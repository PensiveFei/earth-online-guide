# 切菜基础

## 基本准备

家常菜用切片刀或中式菜刀。刀要锋利，钝刀更容易打滑伤手。砧板下垫湿布或防滑垫，防止滑动。

## 基本刀法

切片时手指内扣成“猫爪手”，指关节抵住刀面，刀刃贴着指关节上下移动，边切边退。切丝先切片，再把片码齐切丝。切丁先切条，再切丁。滚刀块适合萝卜、土豆等，食材滚动着切，每块大小相近。蒜、姜可先拍松再切末。

## 安全要点

眼睛看刀与食材，不要切太快。另一手保持猫爪手，指尖向内，不要指头伸平。生熟分开，切肉和切菜的砧板刀具分开使用。用完后及时清洗擦干。

## 必要物品与费用

菜刀、砧板、防滑垫或湿布、待切食材。基础菜刀和砧板通常几十元即可，没有额外使用费用。

## 容易踩错的点

- 手指伸平被切
- 砧板滑动
- 用钝刀用力过猛
- 边切边聊天分心
- 生熟混用砧板

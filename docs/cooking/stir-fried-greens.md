# 炒青菜

## 操作流程

去掉老叶、黄叶和根部。用流水冲洗叶片和茎部，可先浸泡几分钟再冲洗，洗去泥沙。洗后尽量沥干，避免下锅后大量出水。

叶菜可手掰或切段，茎和叶分开。蒜切末备用。锅烧热后放油，油温五成热放蒜末爆香，不要炸焦。先下茎、梗等不易熟的部分翻炒，再下叶片。全程大火快炒。

出锅前加盐，可加少许糖或鸡精。绿叶菜炒软、颜色变深即可出锅，一般1至3分钟。水分多的菜可大火收一下或勾薄芡。

## 必要物品与费用

炒锅、锅铲、青菜、食用油、盐、蒜。常见青菜每斤约2至6元，一人份约200至300克。

## 容易踩错的点

- 菜不沥水下锅出水多
- 火小变成焖煮
- 盐放太早导致出水
- 蒜末炸焦发苦
- 炒过头发黄变软

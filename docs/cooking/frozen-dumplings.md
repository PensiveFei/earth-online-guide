# 煮速冻水饺

## 操作流程

锅要大，水量要能没过饺子。大火烧开。水开后下入速冻水饺，不要解冻。下锅后立即用锅铲背或漏勺沿锅底轻推，防止粘底。

水再次沸腾后加一小碗凉水，转中火。重复点水2至3次，直到饺子全部浮起、鼓肚、皮变得半透明。一般煮7至10分钟，以包装说明为准。捞出后用漏勺沥干，可配醋、生抽、辣椒油。

判断是否熟透：饺子浮起后再煮1至2分钟，夹开一个看馅料是否热透，皮没有生白。

## 必要物品与费用

锅、漏勺或锅铲、速冻水饺、水、蘸料。速冻水饺每袋500克约10至30元，一人份约15至20个。

## 容易踩错的点

- 水没开就下锅
- 下锅后不推底导致粘锅
- 一次煮太多水溢锅
- 浮起就捞出导致馅未熟
- 解冻后下锅粘连破皮

# 蒸米饭

## 操作流程

用电饭煲附赠量杯量米。一人食一般放半杯至一杯米，一杯米约150克，煮出约两碗饭。米放入内胆后加清水，轻轻搅动淘洗，倒掉淘米水，重复1至2次即可，不要用力搓洗。

加水按体积比例约1:1.1至1:1.3，即一杯米加一杯多一点的水。新手可用手指测量：米平铺后，水面高出米面约一个指节。新米少加水，陈米多加水，长粒米少加水，东北米或粳米略多加水。

有时间可浸泡10至20分钟。内胆外壁擦干后放入电饭煲，合盖，选择“煮饭”“精煮”或“快煮”。跳闸后不要立即开盖，焖5至10分钟。开盖后用饭勺从下往上翻松，避免底部结块。

## 必要物品与费用

电饭煲、量杯、大米、清水、饭勺。普通大米每斤约3至8元，一人一顿约50至100克生米，成本约0.5至2元，电费很低。

## 容易踩错的点

- 水多煮成粥，水少夹生
- 内胆外壁有水导致电饭煲故障
- 淘米过度搓洗
- 煮好立即开盖口感发粘
- 保温时间太长底部发硬

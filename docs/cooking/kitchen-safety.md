# 厨房安全：燃气与用电

## 燃气安全

使用前确认燃气灶附近没有塑料袋、抹布等易燃物。使用后先关灶具旋钮，再关气源阀门或保持管道阀门关闭。使用中人不离火，锅烧干、溢锅扑灭火焰都危险。

闻到明显燃气味，不要开关任何电器，不要点火，先轻开门窗通风，关闭阀门，到室外拨打燃气公司电话或报警。定期检查软管是否老化、接口是否漏气，可用肥皂水涂在接口处看是否冒泡。不要在厨房存放酒精等易燃液体。

## 用电安全

电饭煲、电磁炉、电水壶、微波炉等使用后及时断电。插座保持干燥，湿手不插拔插头。不要多个大功率电器同时插一个插排。电磁炉工作时不要放在金属台面上，锅具要匹配。

微波炉不能加热整鸡蛋、密封罐头和金属器皿，液体加热后小心暴沸。电饭煲内胆外壁擦干再放入，电源线不要接触热源。发现电器冒烟、有焦味，先断电，不要用水直接扑灭电器火。

## 必要物品与费用

可配灭火毯、干粉灭火器和燃气报警器。灭火毯约20至50元，灭火器约30至80元，燃气报警器约50至150元。定期检查有效期。

## 容易踩错的点

- 燃气泄漏时开灯或开排风扇
- 烧油时离开厨房
- 锅起火时用水浇
- 湿手操作电器
- 微波炉加热鸡蛋
- 多个大功率电器共用插排
- 燃气灶使用后不关阀门或长时间不检查软管

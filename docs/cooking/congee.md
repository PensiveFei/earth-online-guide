# 煮粥

## 操作流程

大米、小米或杂粮均可。大米粥可用1:8至1:10的米水比例，浓粥约1:6。米简单淘洗1至2次。杂粮豆类提前浸泡2小时以上。

米和水一次性加足，冷水下锅。大火烧开后转小火，保持微沸，半盖锅盖防止溢锅。大米粥约煮20至40分钟，杂粮粥约40至90分钟。期间偶尔搅动，防止糊底。

白粥可配小菜。咸粥可加皮蛋、瘦肉、青菜和盐。甜粥可加糖、红枣。省时做法是用电饭煲或压力锅，按“煮粥”键，水量不要超过最高刻度。

## 必要物品与费用

锅或电饭煲、米、水、配料。大米粥一人份约30至50克米，成本约0.3至1元。

## 容易踩错的点

- 水开后继续大火导致溢锅
- 不搅动糊底
- 中途加水影响口感
- 豆类未浸泡煮不烂
- 电饭煲煮粥水量超过刻度

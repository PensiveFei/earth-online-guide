# 炖一锅汤

## 操作流程

排骨、鸡肉、牛肉等肉类冷水下锅，加姜片和料酒，烧开后煮2至3分钟，撇去浮沫，捞出用温水冲洗。这一步去腥去血水。

炖锅或砂锅中加足量冷水，放入焯好的肉、姜片和葱段。水要一次加足，中途尽量不加水。大火烧开后转小火，加盖慢炖。鸡汤约1至1.5小时，排骨汤约1至1.5小时，牛肉汤约1.5至2.5小时。蔬菜类在最后20至30分钟加入，避免炖烂。

出锅前加盐，不要早放盐，否则肉容易发柴。可加白胡椒粉提味。省时做法是用高压锅，上汽后压20至40分钟。

## 必要物品与费用

炖锅、砂锅或高压锅、汤料、姜、料酒、盐。按材料不同，一锅排骨汤约30至60元，鸡汤约30至50元。

## 容易踩错的点

- 肉类不焯水导致汤腥浮沫多
- 焯水用热水导致血水出不来
- 中途频繁开盖或加水
- 盐放太早
- 蔬菜放太早炖烂
- 高压锅使用不当

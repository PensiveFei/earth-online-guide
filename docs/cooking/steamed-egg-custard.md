# 蒸蛋羹

## 操作流程

鸡蛋2个打入碗中，加少量盐，用筷子充分打散。加入温水，蛋水比例约1:1.5至1:2。使用温水，不要用开水，否则蛋液会被烫成蛋花。凉开水也可以。

用细网筛过滤或撇去表面泡沫，减少气孔。碗上盖一个盘子或耐高温保鲜膜，防止蒸汽水滴落破坏表面。蒸锅水烧开后放入，中火蒸8至12分钟，蛋液量多则延长。关火后再焖2分钟。出锅后淋少量生抽、香油，撒葱花。

## 必要物品与费用

蒸锅或普通锅加蒸架、碗、盘子或保鲜膜、鸡蛋、温水、调料。鸡蛋2个约2至4元。

## 容易踩错的点

- 用开水冲成蛋花
- 蛋水比例不对
- 大火蒸过头呈蜂窝状
- 不盖盘导致表面坑洼
- 容器太厚中间不熟

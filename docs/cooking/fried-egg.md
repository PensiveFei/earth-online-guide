# 煎鸡蛋

## 操作流程

不粘锅最省事，铁锅需要先润锅。锅烧热后倒油，油量约1至2汤匙。油温五六成热时，油面微微波动、手掌悬空能感到温热。

先把鸡蛋打入小碗，确认没有蛋壳和坏蛋，再滑入锅中。新手用小火。喜欢单面流心，蛋白凝固、蛋黄仍流心即可出锅；喜欢全熟，可翻面再煎30至60秒。出锅前撒少量盐和黑胡椒。

铁锅防粘方法：锅烧热后倒油润锅，将油倒出，再重新放少量凉油，然后放鸡蛋。

## 必要物品与费用

不粘锅或铁锅、锅铲、食用油、鸡蛋、盐。鸡蛋每个约0.8至2元，食用油用量很少。

## 容易踩错的点

- 火太大外焦内生
- 油温过高溅油
- 鸡蛋直接磕锅边带入蛋壳
- 翻面时蛋黄破
- 铁锅不润锅粘底

# 煮面条

## 操作流程

锅要够大，水量要足，一般每100克干面条配约1升水。大火烧开水，水里可加少量盐和几滴油，减少粘连。

水沸腾后把面条散开下锅，不要整把直接丢入。下锅后用筷子轻轻搅散。保持中大火煮，水再次沸腾后加半碗凉水，重复1至2次，直到面条没有硬芯。细面约2至4分钟，挂面约4至6分钟，鲜面时间更短，以包装说明为准。

捞出前尝一下，没有白芯即可。拌面可捞出后过凉开水防粘；汤面直接捞入碗中。加盐、生抽、香油、葱花、青菜或鸡蛋即可。

## 必要物品与费用

锅、筷子、漏勺、面条、水、调料。挂面每斤约5至15元，一人份100克约1至3元。

## 容易踩错的点

- 水少面糊
- 下面后不搅散导致粘连
- 煮过头软烂
- 时间不够有白芯
- 水沸溢出时调小火或加凉水

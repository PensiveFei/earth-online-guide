# 🤝 投稿与协作

本仓库由 PensiveFei 与 NHY-JPG 两人维护。内容采用 CC BY-SA 4.0——投稿即同意此许可。

## 朋友协作通道（不会 git 也完全 OK）

1. 把你想写的经验写成文字（微信 / Word / 语音转文字都行），发给 PensiveFei
2. PensiveFei 放入草稿区后，由 AI 按[文章模板](/template)整理成稿
3. 你审核定稿（重点核对事实），PensiveFei 入库提交

## 社区投稿

1. Fork 本仓库 → 新建 `feat/xxx` 分支
2. 按[文章模板](/template)写一篇，放进对应板块目录
3. 提交 PR（一个 PR 只做一篇）
4. 维护者审核后合并

## 写作约定

- 第一次视角，步骤可验证（详见模板）
- 涉及医疗 / 法律只写常识并指向专业渠道
- 发现错别字、事实错误，欢迎直接开 [Issue](https://github.com/PensiveFei/earth-online-guide/issues)

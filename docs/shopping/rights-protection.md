# 维权渠道

## 证据准备

保留订单记录、付款凭证、聊天记录、商品页面截图、物流信息、开箱视频、商品照片、对方账号信息。证据越完整，维权成功率越高。

## 维权顺序

网购或二手交易纠纷，先与商家或卖家协商；协商不成向平台投诉举报；仍不解决的，通过12315电话、小程序或全国12315平台投诉；可同步通过黑猫投诉等平台曝光。涉及诈骗的，直接拨打110或96110报警。

## 维权材料

投诉时写清时间、平台、商家名称、订单号、纠纷经过、诉求。附上证据截图。金额较大的，可咨询是否适合向人民法院起诉。

## 容易踩错的点

- 不保留证据
- 超过售后和投诉时效
- 报警太晚错过止付
- 在非官方渠道寻找“维权”服务导致二次被骗
- 只口头协商没有文字记录
## 官方渠道

- [全国 12315 平台](https://www.12315.cn)（网站 / App / 小程序）：消费投诉举报
- 12315 热线；涉嫌诈骗拨 110

# 二手交易

## 交易前

在闲鱼等平台查看卖家信用、实名认证、历史评价和交易记录。要求提供商品实拍图和细节视频。高价值商品如手机、电脑、奢侈品，优先走平台验货担保服务。价格明显偏低的“急出”“急用钱”商品要警惕。

## 交易中

不脱离平台聊天和交易，不扫卖家发的付款码、收款码，不提前确认收货。当面交易选人多的公共场所，最好有人陪同。当面验货，核对商品与描述是否一致。物流交易保留物流单号，签收前验货并录像。

## 交易后

收到货先检查再确认收货。发现假货、货不对板、质量问题，立即联系平台并申请退款。平台纠纷可申请闲鱼小法庭或客服介入。保留全部聊天记录和转账凭证。

## 容易踩错的点

- 脱离平台私下交易
- 提前点确认收货
- 不验货就签收
- 轻信“押金”“定金”“保证金”
- 混淆收款码和付款码
- 在平台外扫不明二维码

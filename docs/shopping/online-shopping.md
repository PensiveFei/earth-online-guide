# 网购避坑

## 交易前

只在正规平台下单，不脱离平台私下转账、扫个人收款码。核实店铺资质，看营业执照、开店时间、粉丝量和评价。价格明显低于市场价的要提高警惕。销量和好评异常多的店注意甄别刷单。

## 交易中

与客服沟通使用平台聊天工具，保留聊天记录。不点击陌生链接，不下载客服发来的不明App。涉及退款、理赔的，只在平台内操作。贵重商品到货后先验货再签收，必要时录开箱视频。

## 交易后

保留订单截图、付款记录、物流信息、商品页面截图。发现问题先与商家协商，协商不成向平台投诉，再向12315等渠道投诉。七天无理由退货适用于多数商品，定制类、鲜活易腐类、拆封后影响二次销售的数字化商品等不适用。

## 容易踩错的点

- 脱离平台交易
- 点击所谓客服发来的退款链接
- 被诱导扫不明二维码
- 不保留证据
- 不验货就签收
- 轻信“低价清仓”“内部渠道”

# 坐公交

## 乘车方式

使用支付宝或微信乘车码、交通联合卡或现金投币。部分城市公交不设找零，需提前准备零钱。分段计价线路需要上车刷一次、下车再刷一次。

## 候车与上车

在公交站台或站牌等候，看清线路方向和停靠站点。可以通过地图App查看实时公交位置和到站时间。上车时从前门上车，刷卡或投币。携带大件行李放稳，避免挡通道。部分线路不招手不停。

## 下车

下车前提前按铃或告知司机。分段计价线路下车必须刷卡，否则可能按全程票价扣费。到站后从后门下车。部分线路不按铃不下。下车前看后视镜确认安全。

## 费用与容易踩错的点

常规公交通常1至2元，空调车或长线公交可能2元起或分段计价。公交卡工本费约20元上下，可退。容易踩错：坐反方向；不按铃导致过站；分段计价忘刷卡；现金没零钱；错过末班车回不了家。

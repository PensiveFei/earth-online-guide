# 住酒店

## 预订

通过连锁酒店官方App、正规平台或电话预订。看清是否含早餐、退订政策、到店付款还是在线支付。预订成功后保留订单号和入住人信息。订房时看差评里是否提到卫生、噪音；确认订单已确认，避免到店无房。

## 入住

到前台出示身份证原件办理入住。未带身份证需到酒店所在辖区派出所开具临时身份证明。多数酒店需缴纳押金，一般100至500元，部分信用住或协议酒店可免押金。拿到房卡和押金单后确认房号、早餐时间、Wi-Fi密码、退房时间。

## 入住期间

进入房间后检查门锁、防盗链、窗户是否正常。贵重物品可放入房间保险箱或前台寄存。注意疏散通道位置。不要随意给陌生人开门，遇到上门推销或可疑人员联系前台。睡觉前反锁门、挂好防盗链。检查猫眼是否被堵、是否有可疑孔洞——关灯拉窗帘，用手机手电照烟感器等位置。不要连公共 WiFi 输入银行卡密码。

## 退房

多数酒店退房时间为中午12:00前，部分可免费延迟至14:00，需提前与前台确认。退房时前台查房，交回房卡，结清房费及其他消费。押金原路退回。需要发票可在前台开具。

## 费用与容易踩错的点

费用包括房费、押金、迷你吧、洗衣、损坏赔偿等。容易踩错：忘带身份证；未确认退房时间导致超时扣费；押金单丢失；未结清房间消费；通过非官方渠道预订无法入住；入住后不锁门；睡觉不反锁门、不挂防盗链；在公共 WiFi 上输入银行卡密码；退房忘拿充电器、证件。

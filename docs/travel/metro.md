# 坐地铁

> 扫码进站、换乘、出站，第一次坐地铁不迷路。

- 难度：⭐☆☆☆☆
- 耗时：按行程 10–60 分钟
- 费用：多数城市 2 元起步，按里程递加

## 准备

- 支付方式四选一：城市地铁官方 App、支付宝 / 微信乘车码、交通联合实体卡、单程票
- 首次使用乘车码需开通并绑定支付方式
- 不同城市乘车码一般需要切换城市后再使用
- 单程票在车站自动售票机购买，部分机器支持扫码支付和现金

## 步骤

1. **安检进闸**：进站先安检，然后刷码、刷卡或投票进闸；扫码时手机亮度调高，距离扫码口 3–5 厘米；单程票投票后取回，出站时需投入回收口
2. **候车**：看清线路方向——站台门上方会显示终点站方向；排队时站在车门两侧，先下后上
3. **换乘**：按站内「换乘」标识走，无需出站重新购票；注意不同线路末班车时间不同
4. **出站**：刷码、刷卡或投入单程票出站；进站和出站应使用同一种支付方式，不要混用；闸机异常或扣费错误，找站务工作人员处理

## 避坑

- 坐反方向
- 未注意末班车时间
- 乘车码未切换城市
- 进站刷 A 方式、出站刷 B 方式，导致无法出站或形成未完成订单
- 大件行李走楼梯不便——可找无障碍电梯

## 常见问题

- Q：进出站必须用同一种方式吗？
  A：是的。进站刷码，出站也要刷码，不要和实体卡混用。
- Q：单程票出站时怎么办？
  A：投入闸机回收口，而不是带走。

## 进阶

- 费用按里程或站点计算，从进站到出站一次完成
- 使用交通卡或乘车码常有折扣或换乘优惠

# 坐地铁

## 进站方式

使用城市地铁官方App、支付宝或微信乘车码、交通联合实体卡、单程票。首次使用乘车码需开通并绑定支付方式。不同城市乘车码一般需要切换城市后再使用。单程票在车站自动售票机购买，部分机器支持扫码支付和现金。

## 安检与进闸

进站后先安检，然后刷码或刷卡或投票进闸。扫码时手机亮度调高，距离扫码口3至5厘米。单程票投票后取回，出站时需投入回收口。

## 候车与换乘

看清线路方向，站台门上方会显示终点站方向。排队时站在车门两侧，先下后上。换乘按站内“换乘”标识走，无需出站重新购票。注意不同线路末班车时间不同。

## 出站

到达后刷码、刷卡或投入单程票出站。费用按里程或站点计算，从进站到出站一次完成。进站和出站应使用同一种支付方式，不要混用。若闸机异常或扣费错误，找站务工作人员处理。

## 费用与容易踩错的点

多数城市2元起步，按里程递加。使用交通卡或乘车码常有折扣或换乘优惠。容易踩错：坐反方向；未注意末班车；乘车码未切换城市；进站刷A出站刷B导致无法出站或形成未完成订单；大件行李走楼梯不便时可找无障碍电梯。

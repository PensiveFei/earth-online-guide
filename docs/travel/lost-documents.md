# 证件丢了怎么办

## 身份证丢失

先联系可能丢失地点，如车站、机场、酒店、餐厅，询问是否有人拾获。确认丢失后，到附近派出所报警并申请补办。可同时办理临时身份证，有效期一般3个月。火车站可在车站公安制证窗口或自助机办理“乘坐旅客列车临时身份证明”，走人工通道进站。机场可通过“民航临时乘机证明”小程序生成电子临时乘机证明，或到机场公安办理。酒店可到所在辖区派出所开具临时住宿证明。补办正式身份证可在户籍地或异地派出所办理，携带户口簿或能证明身份的有效证件。

## 护照丢失

国内发现护照丢失，先报警取得报警回执，再联系所在地出入境管理部门补办。在国外丢失，先到当地警察局报案取得证明，再联系中国驻当地使领馆申请旅行证或补发护照。

## 银行卡丢失

通过银行客服电话或手机App立即挂失、冻结。确认丢失后到银行网点补办新卡。如果手机丢失，先挂失手机卡，再冻结支付账户。

## 手机丢失

先借手机拨打自己号码尝试找回。若无法找回，立即致电运营商挂失SIM卡。登录微信、支付宝等支付工具冻结账户或挂失设备。修改重要账号密码。开启查找手机功能可定位、锁定或擦除数据。报警备案。

## 容易踩错的点

- 出行前没有备份证件电子版
- 证件和银行卡放在同一包内
- 发现丢失后只顾寻找不先挂失
- 火车站临时身份证明只在有效期内有效
- 酒店临时住宿证明需到酒店所在辖区派出所办理，不是任意派出所

# 证件丢了怎么办

> 身份证、护照、银行卡、手机丢了，先做什么、去哪补办。

- 难度：⭐⭐☆☆☆
- 耗时：挂失立办，补办数天至数周
- 费用：补办工本费等

## 身份证丢失

1. 先联系可能丢失地点（车站、机场、酒店、餐厅），询问是否有人拾获
2. 确认丢失后，到附近派出所报警并申请补办；可同时办理临时身份证，有效期一般 3 个月
3. 出行应急替代方案：
   - 火车站：在车站公安制证窗口或自助机办理「乘坐旅客列车临时身份证明」，走人工通道进站
   - 机场：通过「民航临时乘机证明」小程序生成电子临时乘机证明，或到机场公安办理
   - 酒店：到酒店所在辖区派出所开具临时住宿证明
4. 补办正式身份证可在户籍地或异地派出所办理，携带户口簿或能证明身份的有效证件

## 护照丢失

- 国内：先报警取得报警回执，再联系所在地出入境管理部门补办
- 国外：先到当地警察局报案取得证明，再联系中国驻当地使领馆申请旅行证或补发护照

## 银行卡丢失

1. 通过银行客服电话或手机 App 立即挂失、冻结
2. 确认丢失后到银行网点补办新卡
3. 如果手机也丢了，先挂失手机卡，再冻结支付账户

## 手机丢失

1. 先借手机拨打自己号码尝试找回
2. 无法找回则立即致电运营商挂失 SIM 卡
3. 登录微信、支付宝等支付工具冻结账户或挂失设备
4. 修改重要账号密码
5. 开启查找手机功能可定位、锁定或擦除数据
6. 报警备案

## 避坑

- 出行前没有备份证件电子版
- 证件和银行卡放在同一包内
- 发现丢失后只顾寻找、不先挂失
- 火车站临时身份证明只在有效期内有效
- 酒店临时住宿证明需到酒店所在辖区派出所办理，不是任意派出所

## 安全提示

- ⚠️ 丢证件后的第一优先级：先挂失冻结，再慢慢找
- ⚠️ 出行前把证件拍照或扫描备份（电子版存手机或云盘）

## 常见问题

- Q：在车站丢了身份证还能上车吗？
  A：可以。到车站公安制证窗口或自助机办理临时身份证明，走人工通道进站。

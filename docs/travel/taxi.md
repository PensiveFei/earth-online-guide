# 打车

## 网约车

使用滴滴、高德、T3等平台下单。确认上车点和目的地，选择车型。司机接单后核对车牌号、车型和司机信息。上车后坐后排并系好安全带，可使用行程分享功能。到达后按平台计价在线支付。不要脱离平台线下交易，不要扫司机个人二维码付款。

## 出租车

路边扬招或电话叫车。上车后说明目的地，司机应打表计价。到达后按计价器付费，可现金或扫码。下车前索要机打发票。记住车牌号或车内服务监督卡信息。

## 费用与容易踩错的点

出租车费用包括起步价、里程费、等候费，夜间可能有加价。高速公路费、过桥费一般由乘客承担。网约车按平台预估或实际行程计费。容易踩错：上错车未核对车牌；司机要求取消订单私下交易；坐副驾驶不系安全带；夜间独自乘车不留记录；下车忘取物品；出租车不打表或一口价。

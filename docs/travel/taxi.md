# 打车

> 网约车和出租车怎么坐、怎么付、怎么保护自己。

- 难度：⭐☆☆☆☆
- 耗时：视路况而定
- 费用：出租车 = 起步价 + 里程费 + 等候费，夜间可能加价；网约车按平台计价

## 网约车

1. 用滴滴、高德、T3 等平台下单，确认上车点和目的地，选择车型
2. 司机接单后核对车牌号、车型和司机信息
3. 上车后坐后排并系好安全带，可使用行程分享功能
4. 到达后按平台计价在线支付

## 出租车

1. 路边扬招或电话叫车
2. 上车后说明目的地，司机应打表计价
3. 到达后按计价器付费，可现金或扫码
4. 下车前索要机打发票；记住车牌号或车内服务监督卡信息

## 避坑

- 上错车未核对车牌
- 司机要求取消订单私下交易
- 坐副驾驶不系安全带
- 夜间独自乘车不留记录
- 下车忘取物品
- 出租车不打表或一口价

## 安全提示

- ⚠️ 不要脱离平台线下交易，不要扫司机个人二维码付款
- ⚠️ 夜间独自乘车：坐后排、系安全带、开启行程分享
- 高速公路费、过桥费一般由乘客承担，属正常收费

## 常见问题

- Q：司机说「平台取消、私下走更便宜」怎么办？
  A：拒绝。脱离平台后计费、安全、投诉都没有保障。
